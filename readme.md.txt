# Amazon Sales Data Analysis

## Internship Project

**Role:** Data Analyst Intern  
**Organization:** InnoByte Services  
**Project ID:** 78G0OL

## Project Overview

This project analyzes Amazon sales transaction data to identify sales
trends, product preferences, fulfillment performance, B2B/B2C behavior,
geographical patterns, and operational insights.

## Objectives

- Analyze overall sales trends and patterns.
- Identify popular product categories and sizes.
- Evaluate fulfillment methods.
- Analyze B2B and B2C transactions.
- Study geographical sales distribution.
- Analyze operational order statuses.
- Provide actionable business recommendations.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

| Return Rate | 1.65% |

## Key Findings

- T-shirt is the leading product category by recorded sales.
- M is the leading size by recorded sales.
- Amazon fulfillment handles the larger share of orders and sales.
- Merchant fulfillment has a higher cancellation rate than Amazon fulfillment.
- B2C transactions dominate the dataset.
- B2B transactions have a higher Average Order Value than B2C transactions.
- Maharashtra is the leading state by sales.
- Bengaluru is the leading city by sales.
- Cancellation is an important operational issue.
